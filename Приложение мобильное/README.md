Чтобы запустить нужно открыть PowerShell (я пользовался Visual Studio Code и выполя команды через терминал а он свою очердь PowerShell)
затем перейти в папку с проектом в моем случаи выглядело так (cd C:\Users\Admin\Project\MobileApp\flutter_application_1)
после этого нужно выполнить ряд команд:
1. flutter clean (очищает проект от временных и скомпилированных файлов.) делаем на всякий случай
2. flutter pub get  (загружает и устанавливает все зависимости (пакеты), указанные в файле pubspec.yaml.)
3. flutter run (запуск проекта)
при запуске можно выбрать устройство запуска ,чтобы запустить мобильную версию на андройде , я сначала на телефоне включил режим разработчика затем включил отладку по usb.
после чего подключал мобильное устройство к пк и прописавал flutter run после чего автоматически выбиралось мобильное устройство.
так же можно создать apk файл спомощью этой команда flutter build apk.
послечего вы увидеть путь по которому  хранится apk файл.
