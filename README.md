## О проекте

Это учебный проект, созданный в рамках изучения мобильной разработки. Приложение демонстрирует навыки работы с:

- Локальной базой данных (SQLite)
- Архитектурой на основе моделей и менеджеров состояния
- Flutter-виджетами и кастомными интерфейсами
- Работой с файлами (изображения, видео)
- AI-инструментами для ускорения разработки

**Моя роль:** проектирование архитектуры БД, разбиение на модули, контроль над логикой приложения. AI использовался для генерации типовых запросов и шаблонов интерфейса.

## Функциональность

### 👤 Пользователи
- Регистрация и авторизация по номеру телефона
- Просмотр профиля других пользователей
- Поиск пользователей по имени, ID или телефону

### 🤝 Друзья
- Отправка заявок в друзья
- Подтверждение / отклонение заявок
- Просмотр списка друзей
- Статус дружбы (в друзьях / заявка отправлена / не в друзьях)

### 📝 Посты
- Создание постов с текстом и изображениями
- Лайки и дизлайки постов
- Комментирование постов
- Просмотр ленты постов всех пользователей
- Удаление своих постов

### 💬 Чаты и сообщения
- Создание чата с другом
- Отправка текстовых сообщений
- Отметка о прочтении сообщений
- Список чатов с последним сообщением
- Индикатор непрочитанных сообщений

### ⚙️ Настройки
- Скрытие номера телефона от других пользователей
- Светлая / тёмная тема оформления
- Выход из аккаунта
